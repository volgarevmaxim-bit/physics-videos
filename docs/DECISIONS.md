# DECISIONS — physics-videos

- Статика на GitHub Pages, без бэкенда — просто, бесплатно, хватает для дозатора.
- Vite: root `src/`, outDir `../` — корень репо одновременно деплой-каталог Pages; emptyOutDir false, чтобы не терять data/.
- Фиксированное имя бандла assets/app.js без хэша — против накопления мёртвых бандлов при 10-минутном CDN-кэше.
- Состояние в localStorage без сервера: приватность + ноль эксплуатации; ключ physicsVideosProgress, профиль currentProfileId.
- Сиды: маркер `seeded >= SEED_VERSION` — новые поля досеиваются при росте версии.
- Циклическое расписание (dayIndex % длина пула) — фикс залипания unlockedIndices после исчерпания пула (v0.2.0).
- День 0 → открыт только [0]: «вчерашнего» в первый день нет.
- Подписи видео ≤2 слов, стоп-слова не занимают слот (v0.2.2).
- guard isMain в update-available.mjs — импорт модуля в тестах без побочных эффектов.
- progress.schema.json — контракт без клиентской валидации: валидация на CI, не в браузере.
- Источник контента — ранжир №17 GetAClassVideo; поиск новых видео через API — только по специальному указанию пользователя (2026-09-23).
